# DaysFlow

**DaysFlow** 是一个简洁的日、周、月计划网页应用，适合记录每日待办、截止日期、连续活动、长期目标和周清单。它直接在浏览器中运行，无需安装或构建项目。

**在线体验：** <https://mintaoweng-jpg.github.io/daybook/>

## 功能

- **日计划：** 分开记录普通待办和有具体时间的安排。
- **周计划：** 查看一周内的截止待办和连续活动，点击日期即可打开当天计划。
- **月计划：** 浏览当月截止事项和跨日活动。
- **长期目标与 routine：** 单独管理长期事项，可选设置截止日期。
- **周清单：** 创建读书、购物等清单并逐项勾选。
- **通知识别：** 粘贴通知后，网页会尝试识别事项名称、日期、时间和类型；确认后才会添加。
- **本地备份：** 下载 JSON 备份，或从之前的备份恢复。
- **手机适配：** 支持电脑和手机浏览器。

## 使用

打开上方在线体验链接即可使用。也可以下载或克隆此仓库，在现代浏览器中打开 `index.html`。项目目前是一个静态网页，不需要 Node.js、依赖安装或编译步骤。

## 数据与隐私

DaysFlow **没有账户系统和云端数据库**。待办、活动、长期目标和周清单会自动保存在当前浏览器的本地存储中。访问公开网站的其他人使用各自浏览器的数据，不会看到你的计划。

本地记录与浏览器及网站地址绑定。清理网站数据、更换浏览器或换设备后，记录不会自动迁移。请从页面顶部的 **本地数据与备份** 定期下载备份；恢复备份会在确认后替换当前浏览器中的计划记录。

粘贴的通知原文会随事项保存在本地，也会包含在导出的备份中。识别在浏览器内完成，不会发送给 AI 服务。网页在线时会从 Google Fonts 加载字体。
